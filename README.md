# Charizard: Backyard Escape

A small Microsoft MakeCode Arcade game project.

## Premise

Charizard is trapped in Harry Potter's backyard and needs to escape, survive the trip across town, and reach Mario's favorite pizza parlor.

## Controls

- Arrow keys / D-pad: move
- A button: fireball

## Gameplay

1. **Level 1 — Backyard**
   - Grab the golden key.
   - Dodge Harry and his spells.
   - Reach the gate.

2. **Level 2 — Pizza or Bust**
   - Cross the street.
   - Avoid traffic.
   - Reach the pizza parlor.

## Use with MakeCode Arcade

1. Put these files in the root of a GitHub repository.
2. In MakeCode Arcade, use **Import** and select/import the GitHub repository URL.
3. Open `main.ts` in JavaScript/TypeScript view.
4. Run the simulator.

The project intentionally keeps all pixel art directly in `main.ts`, so there are no external image assets to manage.

## Files

- `pxt.json` — MakeCode project configuration
- `main.ts` — complete game code
- `README.md` — project instructions
- `.gitignore` — ignores common generated/editor files

## Notes

This is a fan-made educational prototype using original pixel-art representations rather than copied game/movie assets.
